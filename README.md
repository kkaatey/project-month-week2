# Семантический поиск товаров

Проект второй недели проектного месяца.

В блокноте выполнены подготовка каталога, лексический поиск TF IDF, семантический поиск MiniLM и сравнение качества по метрикам ранжирования.

## Запуск

1. Поместить четыре файла Parquet в папку `data`.
2. Установить зависимости из `requirements.txt`.
3. Запустить `semantic_search_project.ipynb` командой Restart and Run All.

Файлы данных и рассчитанные эмбеддинги не добавляются в Git.
